세션 인계 문서를 작성한다. 이 스킬은 프로젝트에 묶이지 않는다. 템플릿은 이 스킬 디렉터리 안에 있다.

1. 이 스킬 디렉터리의 `references/template.md`를 읽는다. 주석에 적힌 원칙을 따른다.
2. 현재 상태를 수집한다.
   - `git branch --show-current`, `git log --oneline -5`, `git status --short`
   - `.handoff/`의 가장 최근 문서가 있으면 "이전 인계 문서"로 연결한다.
3. 저장소 루트의 `.handoff/YYYY-MM-DD-<주제>.md`(오늘 날짜, 주제는 영어 kebab-case 또는 한글)로 쓴다.
   - 작성자는 지금 실행 중인 도구(`Claude Code` 또는 `Codex`).
   - 저장소를 봐서는 알 수 없는 것만 적고, commit된 내용은 해시로만 가리킨다.
   - 해당 없는 절은 지우지 않고 "없음"으로 적는다.
   - 확인하지 못한 가정은 6절에 따로 적는다.
   - 사용자와 합의하지 않은 내용을 4절(결정)에 넣지 않는다.
4. 프로젝트 지침(`AGENTS.md`·`CLAUDE.md`)에 문서 검사 명령이 있으면 인계 문서 경로를 대상으로 실행하고, 실패하면 고친다. 없으면 건너뛰고 보고에 적는다.
5. 파일 경로와 한 줄 요약만 사용자에게 보고한다. `.handoff/`가 git에서 제외되어 있지 않으면 사용자에게 알린다. 인계 문서는 커밋하지 않는다.
