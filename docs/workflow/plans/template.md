# 실행 계획 제목

## 목표와 근거

로드맵 항목, 관련 ADR, 끝났을 때 관찰할 결과를 적는다.

## 범위

- 포함할 변경
- 범위 밖의 변경

## task

### T1. 독립적으로 검증할 변경

- [ ] 완료
- Blocked by: 없음
- 변경 범위와 제약: 수정할 경로, 보존할 동작, 변경 순서
- 테스트 경계와 선례: 공개 경계, 테스트 모듈, 기존 유사 테스트, 기대 결과
- AC: 저장소 루트에서 실행할 명령을 한 줄씩 적는다. 선행 준비가 필요하면 함께 적는다.

## 최종 검증

시작 SHA부터 HEAD까지 실행할 변경 범위 검사, 저장소 지침에 따른 추가 검사, PR의 CI에서 확인할 E2E 결과를 적는다. 로컬 E2E는 사용자가 명시적으로 요청한 경우에만 검증 명령에 포함한다.
