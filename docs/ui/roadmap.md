- 작성일: 2026-11-26
- 상태: U0 진행 중

web 화면 개편 트랙이다. 서비스 로드맵 [docs/roadmap.md](../roadmap.md)(M 트랙), 워크플로 로드맵 [workflow/roadmap.md](../workflow/roadmap.md)(W 트랙)와 병행한다. 각 단계는 **완료 기준**을 만족해야 다음 단계로 넘어간다. 시각 규칙의 기준은 [UI 가이드](../ui-guide.md)다.

## 단계 요약

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| U0 | 결정 기록과 지침 갱신 | 문서 검사 통과 |
| U1 | 기반: 토큰, 폰트, 프리미티브, 브랜드 시안, 시드, 캡처 스크립트 | 시안 확정, 프리미티브가 기존 화면에 적용됨 |
| U2 | 사용자 흐름 | 모바일·데스크톱에서 목록부터 취소까지 완주, axe 위반 없음 |
| U3 | 주최자·관리자 백오피스 | 백오피스 화면이 같은 토큰·컴포넌트를 씀 |
| U4 | 포스터·장르 백엔드 확장 | 주최자가 올린 포스터와 장르가 목록에 표시됨 |
| U5 | 시각 회귀 테스트 전환 | 기준 이미지 테스트가 web 검사에 포함됨 |

## U1. 기반

- [x] 브랜드 시안 HTML: 인디고 계열 후보를 카드, 버튼, 좌석 칩에 적용해 비교하고 확정([시안](./mockups/brand.html), A안 `#4338CA`)
- [x] `@theme` 시맨틱 토큰(색, 간격, 모서리, 그림자, 타이포그래피), Pretendard 셀프 호스팅(서브셋 4굵기), `lucide-react`
- [x] 프리미티브: Button(4단계), Input, Field, Badge, Card, Dialog·Sheet·Toast(Radix 래핑), 빈 상태·로딩·오류 (`web/src/components/ui/`)
- [x] 헤더와 레이아웃: 워드마크, 모바일 한 줄 헤더와 시트 메뉴, 역할 배지
- [x] 시연 데이터 시드 스크립트(`scripts/dev/seed-demo.sh`, API 호출, DB 초기화 옵션)
- [ ] 전체 흐름 캡처 스크립트(모바일·데스크톱, dev 인디케이터 숨김)
- [x] 개발 환경 대기열 입장 속도 조절 설정(대기 순번 화면 재현용, `run.sh --slow-queue`)
- [ ] `globals.css`의 직접 작성 클래스를 토큰·프리미티브로 대체

**완료 기준**: 시안이 확정되고, 기존 모든 화면이 새 프리미티브와 토큰으로 깨짐 없이 표시된다. `web-check.sh`가 통과한다.

## U2. 사용자 흐름

- [ ] 공연 목록: 생성형 포스터 카드(이미지 슬롯 포함), 모바일 2열 그리드
- [ ] 공연 상세: 포스터 영역, 가격표, 회차 카드
- [ ] 대기열: 순번, 앞 인원, 예상 대기 시간, 진행 바, 안내
- [ ] 좌석 선택: 칩 그리드(색·모양 상태), 무대·범례·툴팁, 방향키 이동, 모바일 폭 맞춤·확대, 하단 요약 바, 데스크톱 요약 패널
- [ ] 결제: 카운트다운과 진행 바, 만료 경고와 다이얼로그, 버튼 위계
- [ ] 예매 완료: 티켓 카드
- [ ] 마이페이지·쿠폰: 카드 목록, 상태 배지, 취소 확인 다이얼로그, 쿠폰 카드
- [ ] 로그인·회원 가입
- [ ] web E2E 선택자·문구 갱신, `@axe-core/playwright` 검사 추가

**완료 기준**: 모바일(390px)과 데스크톱(1440px)에서 목록 → 대기열 → 좌석 → 결제 → 완료 → 취소를 완주한다. `./scripts/e2e/run.sh --web`과 axe 검사가 통과한다.

## U3. 주최자·관리자 백오피스

- [ ] 주최자 대시보드: 지표 카드, 전체 폭 표, 빈 상태
- [ ] 공연 등록: 2열 폼, 좌석 배치 미리보기
- [ ] 관리자 화면(쿠폰 관리 등)

**완료 기준**: 백오피스 화면이 U1의 토큰·프리미티브만으로 구성되고, 모바일에서 잘리는 표가 없다.

- [ ] 시드 스크립트에 장르·포스터 추가
- [ ] `docs/architecture.md`, `AGENTS.md` 5절 갱신

**완료 기준**: 주최자가 올린 포스터와 장르가 목록·상세에 표시되고, E2E가 통과한다.
