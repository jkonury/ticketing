## 이상 징후와 한계

- **queue-surge 이상**: 10,000명 중 1,263명이 등록되지 못했다(realtime 등록 요청 8,737건 = Gateway `realtime-queues` 8,737건). 즉 realtime 도달 전 단계에서 실패했고 상태 코드·발생 구간은 확인하지 못했다. `unexpected_errors` threshold가 미달해 종료 코드 99다. k6 최대 RSS 8,762MB, 호스트 메모리 최대 87.5%로 발생기 쪽 포화 가능성이 있으나 확정하지 못했다. 원인 확인 없이 재실행하지 않아 **A는 1회·미달 결과**로 남기며, 분리 전 A 기준선으로는 쓰지 않는다. 원인 규명 후 재측정이 필요하다.
- A는 1회, B는 3회. 같은 날 앞뒤 회차 외 반복은 없다.
- 결제 확정 지연은 측정하지 못했다(위 절).
- 호스트 단독 환경이며 fake-pg(로컬) 지연은 실제 PG와 다르다.
