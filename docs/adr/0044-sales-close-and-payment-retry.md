# ADR 0044: 회차 시작 시 판매 마감과 결제 재시도

- 상태: 합의
- 작성일: 2026-11-20

- 결정 주체: 사용자 합의
- 대체: [ADR 0025](0025-booking-seat-copy-cache.md)의 좌석 사본 값과 회차 정보 조회 범위
- 대체됨·일부 변경: 없음
- 관련: [핵심 흐름](../architecture/flows.md), [API 규약](../architecture/api-conventions.md)

## 배경

공연이 시작된 뒤 신규 예매와 최초 결제 요청을 받으면 이미 시작된 회차의 좌석을 판매할 수 있다. 동시에 네트워크 오류로 재전송된 요청은 기존 결과를 확인할 수 있어야 한다. 기존 좌석 사본 캐시는 시작 시각을 포함하지 않는다.

## 결정

1. 회차 시작 시각부터 새 예매와 최초 결제 요청을 거절한다. 예매 및 결제의 기존 멱등 재호출과 결제 결과 처리는 허용한다.
2. 좌석 사본 캐시에 시작 시각을 함께 저장한다. 이전 캐시나 손상된 값은 DB 사본으로 보완한다. 결제 최초 접수는 DB 회차 사본으로 확인한다.
3. 결제 접수 이력이 있는 CONFIRMED 예매의 재요청은 이벤트 재발행 없이 현재 상태를 반환한다.

## 검토한 대안

| 대안 | 채택하지 않은 이유 |
| --- | --- |
| 모든 예매에 DB 회차 조회 | 정상 선점의 DB 사전 조회를 추가한다. |
| 시작 후 모든 요청 거부 | 이미 처리한 요청의 결과를 재확인할 수 없다. |

## 결과

캐시 적중 시 추가 DB 조회 없이 마감 여부를 판단한다. 기존 캐시는 최초 조회 때 DB로 보완하며, 결제 최초 접수에는 회차 사본 조회가 추가된다. 회차 시작 시각을 변경하는 기능이 생기면 캐시 무효화가 필요하다.
