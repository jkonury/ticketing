# 0014. SSE는 BFF를 우회해 Gateway에 직접 연결

- 상태: 수락
- 일자: 2026-11-10

## 맥락

일반 API 요청은 전부 BFF를 거친다. SSE는 연결이 오래 유지되므로, BFF를 거치게 하면 Node 프로세스가 연결을 계속 붙들게 된다. 한편 JWT는 브라우저에 노출하지 않기로 했다 ([0013](0013-jwt-behind-bff.md)).

## 검토한 대안

- (a) 브라우저 → Gateway → 실시간 앱 직접 연결. BFF가 발급한 단기 SSE 티켓으로 인증한다.
- (b) 브라우저 → BFF → Gateway로 프록시한다.

## 결정

**(a)** 로 한다. Gateway가 SSE 티켓을 검증한다.

## 결과

- BFF가 장기 연결을 유지하지 않아도 된다.
- 토큰은 여전히 브라우저에 노출되지 않는다. 브라우저가 갖는 것은 수명이 짧은 SSE 티켓뿐이다.
- "브라우저는 백엔드를 직접 호출하지 않는다"는 규칙에 예외가 하나 생긴다.
- 브라우저가 Gateway에 직접 붙으므로 CORS 설정이 필요하다.
- 티켓의 수명이 짧으므로 재연결할 때마다 새로 받아야 한다.
