# ADR 0017: Spring Boot 4.1과 Spring Cloud 호환성

- 날짜: 2026-11-10
- 상태: 수락

## 배경

Spring Cloud 2025.1의 공식 지원 범위는 Spring Boot 4.0.x이며, 설계의 최신 안정판 선택인 Boot 4.1.x는 공식 호환이 확인되지 않았다.

## 결정

사용자의 선택에 따라 Boot 4.1.x를 유지한다. Spring Cloud 2025.1과의 조합은 공식 지원이 확인되지 않은 상태로 기록하고 Gateway 기동을 검증한다. 호환성 검증을 비활성화하여 실패를 감추지 않는다.

## 대안과 결과

Boot 4.0.x를 선택하면 공식 지원 조합을 사용할 수 있지만 최신 안정판을 유지한다는 선택과 다르다. 현재 조합은 Gateway에서 호환성 오류가 날 수 있으며 공식 지원을 보장하지 않는다.
