# 0009. 실시간 앱은 Redis만 사용

- 상태: 수락
- 일자: 2026-11-10

## 맥락

실시간 앱은 대기 순번과 좌석 현황을 SSE로 내보낸다. 좌석 현황의 원본은 코어의 PostgreSQL에 있다.

## 검토한 대안

- (a) Redis만 사용한다. PostgreSQL에는 접근하지 않는다.
- (b) R2DBC로 PostgreSQL도 직접 조회한다.

## 결정

**(a)** 로 한다. 접속 직후의 초기 좌석 현황은 코어가 Redis에 유지하는 **스냅샷**에서 읽고, 이후 변경분은 Redis Streams 구독으로 받는다.

## 결과

- 실시간 앱이 상태를 갖지 않아 k8s에서 수평 확장이 쉽다.
- 실시간 앱이 코어의 DB 스키마에 묶이지 않는다.
- 코어는 좌석 상태가 바뀔 때마다 스냅샷 갱신과 Streams 발행을 해야 한다.
- 스냅샷은 표시용이다. 실제 선점 가능 여부는 코어의 선점 처리 결과로만 판단한다.
